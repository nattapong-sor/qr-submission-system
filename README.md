# 📚 ระบบสแกน QR บันทึกการส่งชิ้นงาน

ระบบเว็บสำหรับคุณครู: นักเรียนแต่ละคนมี QR รหัสประจำตัว เวลาส่งชิ้นงาน
ครูเลือกวิชา/ชิ้นงานที่กำลังเช็ค แล้วสแกน QR ผ่านกล้องมือถือ/แท็บเล็ตในเบราว์เซอร์
(ไม่ต้องลงแอป) ระบบจะบันทึกอัตโนมัติว่าใครส่งงานชิ้นไหนแล้วบ้าง
รองรับครูหลายคนใช้งานพร้อมกัน และมีหน้าสรุปผลปลายเทอม export เป็น Excel ได้

## โครงสร้างไฟล์

```
qr-submission-system/
├── index.html          หน้าเข้าสู่ระบบ / สมัครบัญชีครู
├── scan.html            หน้าหลัก: เลือกวิชา+ชิ้นงาน แล้วสแกน QR
├── dashboard.html        จัดการรายวิชาและชิ้นงาน
├── students.html         จัดการรายชื่อนักเรียน + สร้าง/พิมพ์ QR
├── report.html            สรุปผลปลายเทอม + ดาวน์โหลด Excel
├── assets/
│   ├── supabaseClient.js  การเชื่อมต่อฐานข้อมูล (ต้องแก้ค่า URL/KEY)
│   └── style.css           สไตล์ของทั้งเว็บ
├── schema.sql               คำสั่งสร้างตารางฐานข้อมูล (รันใน Supabase)
└── README.md
```

ไม่มี backend server แยกต่างหาก — ทุกหน้าคุยกับฐานข้อมูล **Supabase**
โดยตรงผ่าน JavaScript ในเบราว์เซอร์ ทำให้ deploy ง่าย (เป็นเว็บ static ธรรมดา)

## วิธีติดตั้ง (ทำครั้งเดียว)

### 1) สร้างโปรเจกต์ Supabase (ฟรี)
1. ไปที่ https://supabase.com สมัคร/ล็อกอิน แล้วกด "New project"
2. รอสร้างโปรเจกต์เสร็จ (ประมาณ 1-2 นาที)
3. ไปที่เมนู **SQL Editor** > New query > วางเนื้อหาทั้งหมดจากไฟล์ `schema.sql`
   ในโปรเจกต์นี้ แล้วกด Run — จะได้ตารางครบทั้งหมด
4. ไปที่ **Project Settings > API** คัดลอกค่า:
   - `Project URL`
   - `anon public key`
5. เปิดไฟล์ `assets/supabaseClient.js` แก้ค่า `SUPABASE_URL` และ
   `SUPABASE_ANON_KEY` เป็นค่าที่คัดลอกมา

### 2) (แนะนำ) ปิดการยืนยันอีเมลตอนสมัคร เพื่อความสะดวกของครู
ใน Supabase: Authentication > Providers > Email > ปิด "Confirm email"
(ถ้าไม่ปิด ครูที่สมัครใหม่ต้องกดยืนยันในอีเมลก่อนถึงจะล็อกอินได้)

### 3) Deploy ขึ้นเว็บจริง
เนื่องจากเป็นเว็บ static ล้วนๆ เลือก deploy ได้หลายทาง เช่น:
- **Render.com** (Static Site) — New > Static Site > เชื่อม GitHub repo นี้ >
  Build command เว้นว่าง, Publish directory ใส่ `.`
- หรือ GitHub Pages / Netlify / Vercel ก็ได้เหมือนกัน

### 4) สร้างบัญชีครูคนแรก
เปิดเว็บที่ deploy แล้ว กด "สมัครสำหรับคุณครู" เพื่อสร้างบัญชีแรก
ครูคนอื่นๆ ก็สมัครบัญชีของตัวเองได้เช่นกัน (ทุกคนเห็นข้อมูลร่วมกันทั้งโรงเรียน)

## วิธีใช้งานสำหรับครู
1. **นักเรียน** → เพิ่มรายชื่อนักเรียน (เพิ่มทีละคน หรือวาง CSV ทีเดียวหลายคน)
   แล้วเลือกนักเรียน กด "พิมพ์ QR ที่เลือก" เพื่อพิมพ์ QR ไปแปะสมุด/บัตรนักเรียน
2. **วิชา/ชิ้นงาน** → สร้างวิชาที่สอน แล้วเพิ่มชิ้นงาน/ใบงานที่จะเช็คในแต่ละวิชา
3. **สแกน** → เลือกวิชา+ชิ้นงานที่กำลังเช็ค แล้วสแกน QR นักเรียนต่อเนื่องได้เลย
4. **สรุปผล** → เลือกวิชา ดูตารางว่าใครส่งชิ้นไหนแล้วบ้าง ดาวน์โหลดเป็น Excel ได้

## ต่อยอดเพิ่มเติม (ไอเดียสำหรับครูที่อยากพัฒนาต่อ)
- เพิ่มระบบแจ้งเตือน (LINE Notify) เมื่อมีนักเรียนส่งงาน
- เพิ่มหน้าสรุปผลรายห้อง/รายคน แบบละเอียด
- จำกัดสิทธิ์ไม่ให้ครูลบข้อมูลของวิชาที่ตัวเองไม่ได้สอน (แก้ policy ใน `schema.sql`)
- เพิ่ม dark mode หรือปรับดีไซน์ตาม `assets/style.css`
- ทำเป็น PWA ให้ติดตั้งเป็นแอปในมือถือได้ (ใช้งานสแกนได้ลื่นขึ้น)

โค้ดแยกเป็นไฟล์ตามหน้าที่ชัดเจน แต่ละไฟล์อ่านและแก้ไขได้อิสระ
โดยฐานข้อมูลกลางอยู่ที่ Supabase ทำให้ต่อยอด/แก้ไขหน้าตาได้โดยไม่กระทบข้อมูล
